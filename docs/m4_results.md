# LiLi 复现结果（M3/M4）

日期：2026-10-09。对象：`docs/2609.17145v2.pdf`。方法见 `docs/validation_plan.md`，
检测器实现见 `docs/handover_lili_m3.md`。

## 0. 一句话结论

**论文的算法本身已忠实复现**（几何/代数流程逐行对应 Algorithm 1），在无噪声合成数据上
子空间与解析真值的最大主角 ≤ 0.11°（H1）、非退化场景零假阳性（H4），且"数据重关联"
被证明是关键机制（H3 消融显著变差）。**但论文的对照优势（H2：相对 Hessian 法把误差降低
约 50%）在本合成基准上没有复现**——因为论文里 Zhang 法失效的前提（真实扫描、法向估计误差、
大范围重关联歧义）在本基准里不成立，此处 Zhang 法几乎和真值一样好。这是一个**有效的负面
结论**，与 M2 交接文档的已知发现一致。

## 1. 复现方式

```bash
cd src/LiLi_Test/build
cmake .. -DCMAKE_BUILD_TYPE=Release && cmake --build . -j4

./lili_eval --q-samples 16                    # 单点对照（Zhang vs LiLi vs 消融）
./lili_experiment --seeds 3 --q-samples 16 --out /tmp/subset.csv          # 全矩阵
./lili_experiment --seeds 3 --q-samples 16 --local-scale 2 --local-phase 0.5 \
    --out /tmp/independent.csv                # 独立采样（更难）
ctest --output-on-failure                     # 9 个用例
```

结果 CSV 已存档：`docs/m4_subset.csv`（局部=参考子集）、`docs/m4_independent.csv`
（局部独立采样），各 523 行，列含 `sweep,seed,scene,noise,k,tau_pca,tau_disp,method,
true_dim,dim,max_angle_deg,Q`。

## 2. 无噪声对照（H1 / H4）

`./lili_eval`（σ=0，局部=参考子集）：

| 场景 | 真值维数 | Zhang 维数 | LiLi 维数 | Zhang 主角 | LiLi 主角 | Q_Zhang | Q_LiLi |
| --- | --- | --- | --- | --- | --- | --- | --- |
| plane | 3 | 3 | 3 | 0.00° | 0.00° | 0.0230 | 0.0229 |
| closed_cylinder | 2 | 2 | 2 | 0.00° | 0.00° | 0.0231 | 0.0233 |
| open_cylinder | 2 | 2 | 2 | 0.00° | 0.00° | 0.0231 | 0.0235 |
| sinusoidal_cylinder | 1 | 1 | 1 | 0.00° | 0.00° | 0.0112 | 0.0112 |
| screw_tube | 1 | **2** | 1 | 0.78° | 0.10° | 0.0118 | **0.0083** |
| random_surface | 0 | 0 | 0 | — | — | 0.0000 | 0.0000 |

- **H1 成立**：LiLi 在每个退化场景恢复到真值子空间，最大主角 ≤ 0.11°。
- **H4 成立**：非退化对照报 0 维。
- 唯一 LiLi 明显更好的地方是 `screw_tube`：Zhang 多报一维（2 vs 1），LiLi 报对。

## 3. 噪声扫描（H2 / H3）

3 个种子取均值（`docs/m4_subset.csv`，局部=参考子集）。σ=0.02 时：

| 场景 | 真值 | Zhang 维数/主角/Q | LiLi 维数/主角/Q | 消融 维数/主角/Q |
| --- | --- | --- | --- | --- |
| plane | 3 | 3 / 0.3° / 0.0357 | 3 / 2.6° / 0.0363 | 3 / 29.3° / 0.1123 |
| closed_cylinder | 2 | 2 / 1.2° / 0.0386 | 2 / 3.3° / 0.0391 | 2.7 / 50.5° / 0.1458 |
| open_cylinder | 2 | 2 / 1.2° / 0.0394 | 2 / 7.6° / 0.0403 | 2.7 / 27.4° / 0.2026 |
| sinusoidal_cylinder | 1 | 1 / 5.1° / 0.0313 | 1 / 7.8° / 0.0312 | 3.7 / 67.4° / 0.2121 |
| screw_tube | 1 | 2 / 8.4° / 0.0185 | 1 / 14.7° / 0.0179 | 1.7 / 35.2° / 0.0498 |
| random_surface | 0 | 0 / — / 0.0324 | 0 / — / 0.0324 | **3 / — / 0.1605** |

- **H2 不成立**：任何场景任何噪声下都没有 `Q_LiLi ≤ 0.5·Q_Zhang`（0/6）。两法 Q 基本
  相等，因为此处 Zhang 法没有失效。噪声下 LiLi 的主角上升甚至比 Zhang 快——它的 PCA 只
  基于 6 个样本（3 个耦合扰动 ±），统计上比 Zhang 直接用整张 Hessian（600+ 点）更易受噪声影响。
- **H3 成立（机制层面）**：冻结对应关系后，维数普遍多报、主角 >50°、`Q` 涨 3–5 倍；在
  非退化对照上直接产生 3 维假阳性。**说明"显式重关联"确实是 LiLi 的承重机制**。
- 独立采样（`--local-scale 2 --local-phase 0.5`）让 Zhang 的主角略增（open_cylinder
  σ=0.02 从 1.2° 增到 2.0°），但仍远未到论文所述的"完全误判"，H2 依旧 0/6。

## 4. 扰动尺度 k 扫描（σ=0.02，`docs/m4_subset.csv` sweep=k）

| 场景 | k=1 | k=3 | k=5 | k=10 |
| --- | --- | --- | --- | --- |
| plane | dim3 / 9.8° | dim3 / 2.6° | dim3 / 1.3° | dim3 / 0.7° |
| open_cylinder | dim1.7 / 30.1° | dim2 / 7.6° | dim2 / 3.6° | dim2 / 1.5° |
| screw_tube | dim2 / 79.9° | dim1 / 14.7° | dim1.3 / 12.5° | dim2.7 / 37.4° |
| random_surface | dim0 / — | dim0 / — | dim0 / — | **dim2.3 / Q=0.198** |

- k=1 扰动太小（信噪比不足），k=3–5 最佳，**k=10 太大**：扰动足以让优化在非退化场景里
  也"滑走"，非退化对照开始假阳性。
- 结论：k 决定扰动是否"大到能暴露退化、又小到留在代价盆地内"，默认 **k=3** 合理。

## 5. 阈值敏感性（σ=0.02）

`docs/m4_subset.csv` sweep=threshold：

- **τ_PCA**（相对 λ_max）：0.01 会在 `screw_tube` 多报一维；0.03 全场景维数正确；
  0.10 会在 `open_cylinder` 漏报（主角 59.7°）。默认 **0.03** 是唯一全对的取值。
- **τ_displacement**：0.05 / 0.10 / 0.30 在 σ=0.02 下**几乎无差别**——噪声把一切都推过
  门限。它真正起作用的地方是无噪声非退化对照（默认 0.10 让 `random_surface` 报 0 维）。

## 6. 假设判定汇总

| 假设 | 判据 | 结果 |
| --- | --- | --- |
| H1 | 无噪声 LiLi 主角 ≤ 5° | **成立**（≤ 0.11°） |
| H2 | 噪声下 `Q_LiLi ≤ 0.5 Q_Zhang` | **不成立**（0/6；本基准 Zhang 不失效） |
| H3 | 冻结重关联使优势减半 | **机制成立**（消融显著变差、产生假阳性）；因无优势，结论落在机制一侧 |
| H4 | 非退化场景零假阳性 | **成立**（LiLi 报 0 维） |

## 7. 结论与局限

1. **算法复现成功**：Algorithm 1 的每一步都在 `src/lili_detector.cpp` 中一一对应并
   通过测试（H1、H4），`screw_tube` 上还优于 Zhang。
2. **对照优势未复现**：论文 Table I 的核心卖点（噪声/复杂场景下比 Zhang 好约 50%）
   在本合成基准上不成立，因为这里 Zhang 法几乎不失效。根因是基准与论文条件的差距：
   法向是解析精确的、局部扫描是完整参考的子集/规则采样，Hessian 条件良好。
3. **论文的机制解释得到支持**：重关联消融（H3）一致地劣化结果，甚至在非退化场景产生
   假阳性——这是对论文"优势来自显式重关联"这一主张的直接证据。
4. 真实隧道数据的 ATE/RPE 仍未复现（数据未公开，见 `validation_plan.md` §8）。
5. 若要进一步逼近论文的 H2，需要构造"局部扫描只覆盖参考一小部分 + 大初值偏移 + 法向
   估计误差"的设置，让 Hessian 法真正崩溃——这属于**加难基准**，而不是调参去迎合结论。
